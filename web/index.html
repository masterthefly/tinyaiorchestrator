          6. Rules or a model?

          The Classifier is the one agent whose job a language model can do. We trained a 1 million parameter model on about 2,000 labelled log lines and put it beside the rules. Which is better? It depends on the question, so there are three tests, each answering a different one:

          • Trained wordings: fresh examples of phrasings it learned. Did it learn?
          • New wordings: phrasings it never saw. Does it generalise?
          • Real world style: 72 lines written by hand in the style of nginx, Postgres, Java, Kubernetes and so on, used for nothing else.

          For developers

          A connector is a name, a description, named arguments and a read function that returns text. It is the same shape as a tool in an agent, and as a tool served over MCP. To connect a new source, write one and pass it in.
